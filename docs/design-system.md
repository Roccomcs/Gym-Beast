# Diseño

Interfaz en español rioplatense. Fondo oscuro, superficies de alto contraste y acento lima. Jerarquía centrada en el próximo entrenamiento y barra inferior con cinco secciones. Campos numéricos con etiquetas visibles y controles táctiles amplios. Usar Geist para títulos y el sistema operativo como respaldo. Respetar áreas seguras y reducción de movimiento.
